# Dataset Files

## English

The raw dataset files are not included in this repository.

To run the analysis:

1. Download the [Global Superstore dataset from Kaggle](https://www.kaggle.com/datasets/fatihilhan/global-superstore-dataset).
2. Place the downloaded `superstore.csv` file in this directory.
3. Run `prepare_sql_data.py` from the project root to generate the SQL-ready dataset, following the instructions in the main README.

Please check the dataset source and its applicable license before redistributing the data.

## فارسی

فایل‌های داده خام به‌دلیل رعایت شرایط انتشار، در این مخزن قرار نگرفته‌اند.

برای اجرای تحلیل:

۱. مجموعه‌داده‌ی [Global Superstore را از Kaggle](https://www.kaggle.com/datasets/fatihilhan/global-superstore-dataset) دانلود کنید.

۲. فایل `superstore.csv` را در همین پوشه قرار دهید.

۳. طبق راهنمای README اصلی، اسکریپت `prepare_sql_data.py` را از پوشه اصلی پروژه اجرا کنید تا فایل آماده‌ی ورود به SQL تولید شود.

پیش از بازنشر داده‌ها، شرایط مجوز و استفاده از مجموعه‌داده را بررسی کنید.
